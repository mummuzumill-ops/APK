# BSDVP Academy — Decompiled APK

This repository contains a decompiled Android APK extracted with Apktool for research and archival purposes. It is not the original source project and may not rebuild without additional dependencies and signing configuration.

- Package: com.szlwfh.ijkyoi
- Version: 1.1.6 (version code 16)
- Minimum Android SDK: 23
- Target Android SDK: 36
- Decompiled with Apktool 2.11.1

## Download and extract

The archive is split into 8 MiB parts because GitHub API uploads have request-size limits. Download every file named apk-work-decompiled.tar.gz.part-XXX into one directory, then run:

```sh
cat apk-work-decompiled.tar.gz.part-* > apk-work-decompiled.tar.gz
tar -xzf apk-work-decompiled.tar.gz
```

## Safety note

Credentials found embedded in the decompiled APK were replaced with placeholders before this public upload. Any original keys should be revoked or rotated.
